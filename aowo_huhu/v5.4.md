# 嗷呜虎虎 v5.4

## 基本信息
- 权重文件：`aowo_huhu_v5.4.safetensors`（52M，dim 64 / alpha 32）
- sha256：`57bd843bb940c1999bda67b262285e5279785db1c66ffe7d090423a80831f992`
- 基座：SD1.5 `sd15-v1-5-pruned-emaonly.safetensors`
- 触发词：`ohw woman`
- 定位：当前画质最好的一版。脸更立体、发丝更细，衣服细节完整。

## 训练配置
- 数据集：`dataset_v6x`，**74 张**（15 张原图 × 三种裁切 × 水平翻转，部分因裁切越界或缺脸丢弃）
- 三种比例：1:1 脸（768²）/ 3:4 胸像（768×1024）/ 2:3 全身（683×1024）
- 分辨率 832（分桶 704~1152）、batch 1、2600 步
- 优化器 AdamW8bit、lr 1e-4、min_snr γ=5、noise_offset 0.02
- 只训 UNet + full_fp16 + sdpa + 梯度检查点 + 缓存 latent
- 显存峰值 2848MiB，训练约 26 分钟
- 训练脚本：`train/train_v6x.sh`

## 推荐出图参数
- 尺寸 768×1024、LoRA 权重 0.85、steps 28、cfg 6.5、dpmpp_2m + karras
- 建议配 Canny 约束（见 `notes/自训LoRA生图流水线.md`）

## 与 v5.1 的差别
- 优点：脸立体、虹膜有层次、发丝分层、金边与系带完整
- 中性：整体色调更冷，妆更浓
- 未改善：露胸（素材属性）、手部细节、偶发身材比例拉长

## 中间档
每 500 步存一档（500/1000/1500/2000/2500），如果最终版过拟合，可退到 2000 或 2500 试。
