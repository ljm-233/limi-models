# 嗷呜虎虎 v2

拆成"脸"和"身体"两个 LoRA 分别训的第一代。

- 权重：
  - 身体：`seo_v2_800.safetensors`（37M，512，800 步）
  - 脸：`seo_face_v2_sd15.safetensors`（37M，512，1600 步）
  - 脸加训：`seo_face_v2_2400.safetensors`（37M，512，2400 步，**这套脸最稳，后面一直拿它当脸的基准**）
- sha256（2400 版）：`1eecc59669f5c3e4106ac0f1c43b7dbe9bab1dff602da0829d063cb90315bf8d`
- 脚本：`train_sd15.sh`、`train_seo.sh`
- 定位：双 LoRA 串联用的那一代，脸 0.6~0.8 + 身体 0.6~0.7
