# 自定义模型配置库

每个模型一个目录，每版一个 Markdown。只放配置与说明，不放权重。

## 目录规矩
```
models/
  aowo_huhu/            # 模型（嗷呜虎虎）
    v5.1.md             # 版本：训练配置、触发词、推荐权重、已知问题、权重指纹
    v5.4.md
    train_v5.sh         # 该版训练脚本原件
    samples/            # 两三张样例图
```

## 不收进来的东西
- 权重文件（`.safetensors`，单个 40~80MB）→ 网盘或 Git LFS，仓库只留 sha256 与下载地址
- 训练数据集原图（私人照片）→ 只在本地 `~/.dsh/miyu/refs/`，不写进任何仓库

## 新增一版的检查清单
1. 跑完训练，把权重改名成 `<模型名>_<版本>.safetensors`
2. `sha256sum` 记进版本文件
3. 出三张样例图放 `samples/`
4. 把实际用的 `train_*.sh` 复制进来
5. 版本文件写清：分辨率 / dim / 步数 / 数据集与数量 / 触发词 / 推荐权重 / 已知缺陷
